BUNDLE TAG LOG - install on your phone
=======================================

Step 1. Put the app online (once, from a computer)
  - Unzip this file. You get a folder with index.html and other files.
  - Go to https://app.netlify.com/drop
  - Drag the whole folder onto the page.
  - Netlify gives you a link like https://something.netlify.app
  - Create a free Netlify account when it asks, so the link is kept.
    (Without an account the site is removed after a short time.)

Step 2. Install on your phone
  - Open the link in Chrome (Android) or Safari (iPhone).
  - Android: menu (three dots) > Install app.
  - iPhone: Share button > Add to Home Screen.
  - A "Tag Log" icon appears on your home screen.

Step 3. Free Google key (once)
  - In the app, Settings opens by itself.
  - Open aistudio.google.com/apikey, sign in, tap Create API key, copy it.
  - Paste it in the app, tap Test key, then Save.

Daily use
  - Tap "Take photo of tag". Each photo adds the next line.
  - Yellow fields were hard to read: check them against the tag.
  - Tap "Download Excel" any time. The file has every line so far.
  - Photo reading needs internet. The list is saved on the phone.

Notes
  - Photos are sent to Google to be read.
  - Do not share your API key.
